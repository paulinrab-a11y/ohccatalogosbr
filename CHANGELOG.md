# Histórico de alterações

Este arquivo resume as principais mudanças do site OHC Motors. O histórico técnico completo permanece registrado nos commits do GitHub.

## 31/07/2026

- Projeto completo conectado ao GitHub com sincronização bidirecional entre Lovable e a branch `main`.
- Código-fonte, imagens, configurações e histórico anterior preservados no repositório.
- README inicial do projeto adicionado.
- Exportação do catálogo e da memória do projeto em arquivo ZIP.
- Criado este histórico de alterações.

## 29/07/2026

- Adicionado botão de impressão do catálogo.
- Corrigidos os SKUs dos faróis e das lanternas.

## 28/07/2026

- Corrigida a estrutura geral do catálogo OHC Motors.
- Atualizados os SKUs dos volantes.
- Atualizados os ícones do site.

## 27/07/2026

- Adicionados recursos de SEO e sitemap.
- Corrigida a nomenclatura para “Shift Light”.
- Padronizados nomes e imagens dos produtos.
- Aplicado fundo branco às imagens do catálogo.
- Catálogo atualizado a partir do arquivo ZIP consolidado.

## 24/07/2026

- Criada a primeira versão do catálogo OHC Motors.
- Site reestilizado com identidade visual automotiva premium.

## Política de atualização

Toda alteração relevante deve gerar um commit descritivo no GitHub e, quando representar uma mudança funcional ou visual importante, também deve ser registrada neste arquivo.
